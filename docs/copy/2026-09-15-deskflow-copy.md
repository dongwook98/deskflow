# DeskFlow 카피 초안 v1

- 작성: 2026-09-15. 근거: [docs/research/2026-09-15-desk-booking-landing-copy.md](../research/2026-09-15-desk-booking-landing-copy.md) (제품 14개 원문 인용)
- 독자: 사내 좌석 운영 담당자(총무·오피스 매니저). 톤: 담백한 존댓말, 과장 없음. 영문 병기 최소.
- 원칙: **구현된 것만 말한다.** 순위·고객 수·로고·통합·분석 주장 금지(리서치 §4.5). "실시간" 대신 "실시간에 가깝게"(15초 갱신 + 창 포커스 시 갱신이 실제 동작).
- 표기: `[현재]` = 코드에 이미 있는 문구, `[제안]` = 새로 넣거나 바꿀 문구. 시각(Variant)에 맞춰 길이 조절 가능하도록 짧은/긴 버전 병기.

## 0. 한 줄 정의 (모든 곳의 기준 문장)

> DeskFlow — 우리 사무실 배치도 그대로 좌석을 예약하는 도구. 관리자는 에디터에서 배치도를 그리고, 구성원은 그 위에서 빈 좌석을 누릅니다.

## 1. 랜딩 (`/`, 로그인 전)

### 1.1 히어로

**헤드라인 후보** (리서치 §3.1 공식 A+C 결과·고통 제거형, 6~9어절)

| # | 문구 | 근거 |
|---|---|---|
| H1 (권장) | **우리 사무실 배치도 그대로, 좌석 예약은 세 번의 클릭.** | deskbird "in 2 clicks", Skedda "One-tap booking from the map". Officely 의 "지도는 클릭이 2~3배" 반론을 실제 수치(날짜·시간 → 좌석 → 예약하기 = 3)로 선제 대응 |
| H2 | 스프레드시트 없이, 배치도 위에서 좌석을 나눕니다. | Officely·Skedda "Without the Chaos", "messy spreadsheets" 고통 제거형 |
| H3 | 작은 팀을 위한 배치도 기반 좌석 예약 | Robin·Kadence "X for Y" 카테고리 선언형. SEO 용 대안 |

**서브헤드** (1~2문장)
- 긴 버전: 관리자는 에디터에서 좌석·테이블·벽을 끌어다 놓고 저장하면 끝입니다. 구성원은 날짜와 시간을 고르고 배치도에서 빈 좌석을 누르면 예약됩니다.
- 짧은 버전: 관리자는 그리고, 구성원은 누릅니다. 설치도 설정 파일도 없습니다.

**CTA** (리서치 §4.2: 영업형 "데모 신청" 금지, 제품 자체가 CTA)
- 1차: **관리자로 둘러보기** / **구성원으로 둘러보기** — 두 버튼 나란히(데모 계정 원클릭, §2)
- 2차(텍스트 링크): 직접 가입해서 시작하기 → `/signup`
- 로그인 링크: 이미 계정이 있나요? 로그인

### 1.2 히어로 아래 신뢰 줄 (로고 벽 대체, 리서치 §3.6)

로고·숫자 대신 **사실 3개**를 한 줄로:
> 배치도 에디터 · 날짜·시간 단위 예약 · 중복 예약은 데이터베이스가 차단

### 1.3 기능 블록 (순서: 구성원 → 관리자 → 신뢰, 리서치 §4.3)

**블록 1 — 구성원: 배치도에서 고르고 바로 예약**
- 제목: 배치도에서 고르고, 바로 예약
- 본문: 날짜와 시간을 고르면 그 시간에 비어 있는 좌석이 파랗게 표시됩니다. 누르고 예약하기. 끝입니다.
- 범례 문구(스크린샷 캡션): 파랑 = 예약 가능 · 빨강 = 예약됨 · 초록 = 내 예약 · 회색 = 사용 불가  (Robin "Green = Available, Dark grey = Occupied" 방식)
- 보조 문구: 다른 사람이 방금 잡은 좌석은 15초 안에 화면에 반영됩니다.

**블록 2 — 관리자: 배치도 에디터**
- 제목: 그림판처럼 그리는 배치도 에디터
- 본문: 좌석·테이블·벽을 추가하고 드래그로 옮기고 90°씩 돌립니다. 실행 취소·다시 실행, 휠 확대, 격자 맞춤까지. 저장 버튼을 누르기 전까지는 구성원에게 보이지 않습니다.
- 기능 태그(짧은 라벨 6개): 드래그 앤 드롭 · 90° 회전 · 실행 취소/다시 실행 · 확대/축소 · 격자 맞춤 · 저장되지 않은 변경 표시
  - 근거: deskbird "snapping / arrow nudging", Robin "rotation knob / Review and publish" 수준의 구체 동사(리서치 §3.4)

**블록 3 — 신뢰: 중복 예약은 데이터베이스가 막습니다**
- 제목: 같은 좌석, 같은 시간, 두 사람 — 한 명만 성공합니다
- 본문: 예약 겹침 검사는 화면이 아니라 데이터베이스 제약으로 처리합니다. 두 사람이 동시에 눌러도 하나만 저장되고, 나머지는 "방금 다른 사용자가 예약했습니다"를 봅니다.
- 근거: Officely "Double-Booked Rooms? Fixed." 고통 제거형. 실제 구현(exclusion constraint)만큼만 서술

**블록 4 (선택) — 관리자: 저장 충돌도 놓치지 않음**
- 제목: 두 관리자가 동시에 저장해도 덮어쓰지 않습니다
- 본문: 다른 곳에서 먼저 저장됐다면 알려 드리고, 서버 버전을 불러올지 계속 편집할지 고르게 합니다.

### 1.4 "어떻게 동작하나" 3단계 (선택, Robin "How it works" 형식)

1. 공간 만들기 — 이름과 캔버스 크기만 정합니다.
2. 배치도 그리기 — 에디터에서 좌석을 놓고 저장합니다.
3. 구성원이 예약 — 배치도에서 빈 좌석을 누릅니다.

### 1.5 하단 CTA

- 제목: 지금 바로 둘러보세요
- 본문: 가입 없이 데모 계정으로 관리자 화면과 구성원 화면을 모두 볼 수 있습니다.
- 버튼: 관리자로 둘러보기 · 구성원으로 둘러보기
- 각주(작게): 데모 데이터는 주기적으로 초기화됩니다. (← 초기화 스크립트 도입 시에만 표기)

### 1.6 푸터

- DeskFlow · 포트폴리오 프로젝트 · GitHub 링크 · "설계 문서 보기"(docs 링크)
- 명시: 이 서비스는 개인 포트폴리오이며 상용 서비스가 아닙니다.  (리서치 §4.5: 상용처럼 오해될 주장 금지)

## 2. 데모 진입 (원클릭 로그인)

**버튼 라벨**
- 관리자로 둘러보기 — 보조 문구: 공간 만들기, 배치도 에디터, 예약 현황
- 구성원으로 둘러보기 — 보조 문구: 좌석 예약, 내 예약

**진입 직후 안내 배너** (1회, 닫기 가능)
- 관리자: 데모 관리자로 로그인했습니다. 「관리」에서 공간을 만들고 「에디터 열기」로 배치도를 그려 보세요.
- 구성원: 데모 구성원으로 로그인했습니다. 공간을 고르고 날짜·시간을 정한 뒤 파란 좌석을 눌러 보세요.

**실패 시**
- 데모 계정에 잠시 접속할 수 없습니다. 직접 가입해서 이용해 주세요.

## 6. 용어집 (화면 전반 통일)

리서치 §5 기반. 현재 코드와 다른 곳은 `변경` 표시.

| 개념 | UI 용어 | 비고 |
|---|---|---|
| Room | **공간** | 코드·URL(`/rooms`) 그대로. 마케팅 문구에서 "사무실 한 층 = 공간 하나"로 1회 설명 |
| floor plan | **배치도** | 첫 등장 시 "배치도(평면도)" 병기 가능 |
| editor | **배치도 에디터** | 헤더·랜딩 공통 |
| seat / table / wall | **좌석 / 테이블 / 벽** | 툴바 "+ Seat" 등은 `변경` 후보 |
| user(role: user) | **구성원** | "사용자"·"직원" 대신. 관리자 화면 필터 라벨도 동일 |
| admin | **관리자** | — |
| available / reserved / mine / disabled | **예약 가능 / 예약됨 / 내 예약 / 사용 불가** | 범례·상태 select 공통 |
| reserve (button) | **예약하기** | — |
| cancel | **취소** | 예약 카드. 확인 문구 "이 예약을 취소할까요?" |
| my reservations | **내 예약** | 헤더 그대로 |
| admin reservations | **예약 현황** | 헤더 그대로 |
| undo / redo | **실행 취소 / 다시 실행** | 그대로 |
| fit | **맞춤** → `변경` **화면에 맞추기** | 버튼 폭 허용 시 |
| save | **저장** | — |
| dirty | **저장되지 않은 변경사항** | — |
| time range | **날짜 / 시작 / 종료** | 픽커 라벨 그대로 |

## 7. 쓰지 않는 표현 (리서치 §4.5)

[FEATURE 1]
배치도에서 고르고, 바로 예약
날짜와 시간을 고르면 그 시간에 비어 있는 좌석이 파랗게 표시됩니다. 누르고 예약하기. 끝입니다.
파랑 = 예약 가능 · 빨강 = 예약됨 · 초록 = 내 예약 · 회색 = 사용 불가

[FEATURE 2]
그림판처럼 그리는 배치도 에디터
좌석·테이블·벽을 추가하고 드래그로 옮기고 90°씩 돌립니다. 실행 취소·다시 실행, 휠 확대, 격자 맞춤까지. 저장 버튼을 누르기 전까지는 구성원에게 보이지 않습니다.
드래그 앤 드롭 · 90° 회전 · 실행 취소/다시 실행 · 확대/축소 · 격자 맞춤 · 저장되지 않은 변경 표시

[FEATURE 3]
같은 좌석, 같은 시간, 두 사람 — 한 명만 성공합니다

3 구성원이 예약 — 배치도에서 빈 좌석을 누릅니다.
